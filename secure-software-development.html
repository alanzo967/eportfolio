Secure Software Development

In progress. Evidence is added to this page as each unit is completed.

Module aims

This module aims to provide students with:

  • An understanding of the basic principles of secure and sustainable development methodologies.
  • An understanding of the basic principles of architecture, as well as traditional and contemporary Software Development Life Cycle (SDLC) models, such as TOGAF and Agile.
  • An ability to undertake analysis of a real-life problem domain, program design, software construction, and testing required for software development, supporting entrepreneurial coding ideas.
  • Opportunities for exploring software design using the Unified Modelling Language (UML).
  • Experience with code documentation to support maintainable code production.
  • A critical understanding of the concept of abstraction in programming.
  • The ability to put into practice the techniques learned in a team environment, demonstrating how to make compromises, support the equality and diversity of opinion, and be able to critically evaluate the effectiveness of others’ approaches.

Learning outcomes

On completion of this module, I will be able to:

  1. Identify and manage security risks as part of a software development project.
  2. Critically analyse development problems with an entrepreneurial spirit and determine appropriate methodologies, tools and techniques to support secure and sustainable program design and development.
  3. Create software designs using the Unified Modelling Language (UML).
  4. Design and develop/adapt computer programs and to produce a solution that meets the design brief and critically evaluate solutions that are produced.
  5. Systematically develop and implement the skills required to be effective member of a software design team which supports equality and diversity in a virtual professional environment, adopting real-life perspectives on team roles and organisation.
